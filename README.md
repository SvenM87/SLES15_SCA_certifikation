# Vorbereitung auf SUSE Certified Administrator in SLES 15

Dieser deutschsprachige Selbstlernkurs bereitet auf die Prüfung **SCA in SUSE Linux Enterprise Server 15 (2025 Update)** vor. Die Abdeckung folgt den 16 veröffentlichten Zielgruppen.

> Prüfungsangaben können sich ändern. Vor der Anmeldung immer die [offizielle Prüfungsseite](https://www.suse.com/training/exam/sca-sles-15/) prüfen.

## Einstieg

1. [Prüfungsübersicht](kurs/00-pruefungsuebersicht.md) lesen.
2. Die neun Module unter `kurs/` der Reihe nach bearbeiten.
3. Nach jedem Modul das Labor unter `uebungen/` durchführen.
4. Den [Sechs-Wochen-Lernplan](lernplan/6-wochen-plan.md) verwenden.
5. Die [Ziele-Matrix](pruefung/zielematrix.md) und den [Kompetenzcheck](pruefung/kompetenzcheck.md) vollständig abhaken.
6. Mit der [Prüfungssimulation](pruefung/pruefungssimulation.md) abschließen.

| Ordner | Inhalt |
|---|---|
| `kurs/` | Theorie, Befehle, Prüfungswissen und Kontrollfragen |
| `uebungen/` | Geführte Praxisaufgaben für WSL/SLES |
| `lernplan/` | Lernplan und Fortschrittskontrolle |
| `pruefung/` | Simulation und Kompetenzcheck |
| `quellen/` | Quellen, Videos und Handbuchablage |

Für viele Übungen genügt SLES 15 unter WSL 2. Bootloader, initrd, echte Blockgeräte, Btrfs/Snapper-Rollback und realistische Netzwerkdienste sollten zusätzlich in einer entbehrlichen SLES-VM geübt werden.

Die im Auftrag erwähnten Handbücher waren beim Erstellen nicht im Checkout sichtbar. `quellen/handbuecher/` ist als Ablageort vorbereitet. Eine konkrete Kapitelzuordnung kann ergänzt werden, sobald die Dateien vorliegen.
